# FinAI Ledger — projektna pravila

1. GitHub je edini vir resnice za izvorno kodo.
2. `main` predstavlja produkcijsko preverjeno stanje.
3. Razvoj poteka na `develop` ali kratkotrajnih feature vejah.
4. Vsaka pomembna sprememba mora biti verzionirana in sledljiva.
5. Pred večjo produkcijsko spremembo mora obstajati preverjena možnost rollbacka.
6. API ključi, gesla, certifikati in skrivnosti ne smejo biti zapisani v kodi ali GitHubu.
7. Produkcijski podatki se v razvoju ne uporabljajo brez ustrezne zaščite in anonimizacije.
8. Računovodske knjižbe morajo imeti popolno revizijsko sled.
9. AI odločitve morajo biti razložljive in sledljive.
10. Kritične AI odločitve morajo podpirati človeško potrditev.
11. Zaključenih knjižb se ne prepisuje neposredno; uporabljajo se korekcije oziroma storno postopki.
12. FURS, banke, AJPES in druge zunanje integracije se najprej preverjajo v testnem okolju.
13. Aplikacija mora biti responsive in dostopna na desktopu, tablici in telefonu.
14. UI mora biti pripravljen na večjezičnost; slovenščina je referenčni jezik.
15. Varnost, zakonodajna skladnost in pravilnost podatkov imajo prednost pred hitrostjo razvoja.
