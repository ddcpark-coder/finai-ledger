# FinAI LIQUIDITY-DEMO-01

Spremljanje likvidnosti v podpogled **Banka → Pregled → Napoved** vključuje prilagodljive sintetične napovedi denarnega toka za 14 oziroma 30 dni, s scenariji Previdno (50 % pričakovanih plačil terjatev), Osnovno (75 %) in Optimistično (100 %).

Izračun poteka samo v celih centih. Za izbrano demonstracijsko podjetje se seštejejo zapadle sintetične terjatve in obveznosti znotraj izbranega obdobja; ni API dostopa do banke, knjigovodske baze ali AI. Izračun **ni** finančno priporočilo ali zanesljiva poslovna napoved.

Naslednja razvojna faza: avtoriziran uvoz potrjenih bančnih transakcij (npr. ISO 20022), ločena stanja po podjetjih, realni datumi in statusi plačil, pojasnjene negotovosti, potrditev uporabnika, revizija in scenariji po stroškovnih mestih.

Nobenih Hiper M, Laškoteka ali STNG sprememb.
